测试与烧录记录见 [docs/test-report.md](docs/test-report.md)。

故障排查记录见 [docs/troubleshooting.md](docs/troubleshooting.md)。

## 项目说明

这是一个基于 STM32F103C8T6 和 QMK 的 17 键小键盘学习性复刻与代码归档项目，不是原创 PCB 设计。

## 原项目来源

- 原项目页面：<https://oshwhub.com/morempty/STM32-PAD-17jian-shuo-zi-jian-pa>
- 原作者主页：<https://oshwhub.com/morempty>
- 本仓库保留源码中的原有版权和许可证说明。

## 当前内容

- `firmware/qmk/w17/`：QMK 键盘配置、键位映射和相关源码快照。

## 我的工作范围

我完成了本项目的代码整理、编译、固件烧录和实物测试。PCB 设计本身来自原项目，本仓库不把原作者的设计写成原创成果。
