# 完整验收清单

以下是待操作者填写的实物验收表，不代表所有测试已执行。已有证据见[测试记录](test-report.md)。测试前记录系统版本、固件来源、Num Lock 状态及日期。

## 逐键测试

在记事本或键盘测试器中开启 Num Lock，每个键慢按一次、快速点按数次、长按一次。只按一次时应只产生一次事件；长按的数字连发属于系统正常重复行为。

| 键 | 预期 | 结果 |
| --- | --- | --- |
| Num | 单按切换 Num Lock，长按不进入灯效层 | 待测 |
| `/`、`*`、`-`、`+` | 对应运算符，每键分别测试 | 待测 |
| `0`、`1`、`2`、`3`、`4` | 对应数字，每键分别测试 | 待测 |
| `5`、`6`、`7`、`8`、`9` | 对应数字，每键分别测试 | 待测 |
| `.` | 对应小数点；显示符号可能受系统区域设置影响 | 待测 |
| Enter | 换行或确认 | 待测 |

## 连接与稳定性

| 测试 | 操作与通过条件 | 结果 |
| --- | --- | --- |
| Num Lock 状态 | 分别开、关 Num Lock；关闭时数字键可能作为导航键，不应误判为坏键 | 待测 |
| 同时按键 | 键盘测试器中同时按 3 个数字，均有独立按下/释放事件且松开后无残留 | 待测 |
| USB 拔插 | 完整拔插 3 次，每次恢复输入，记录系统的 Num Lock 状态 | 待测 |
| 睡眠唤醒 | 电脑睡眠后唤醒，确认数字输入与 RGB 恢复 | 待测 |
| 动态键位保存 | Vial 设置 Num Lock 后拔插，确认仍为普通 Num Lock | 待测 |
| 长时间使用 | 正常使用至少 30 分钟，记录是否漏键、连击或断连 | 待测 |
| 装配手感 | `0`、`+`、Enter 回弹顺畅，按压外壳不会使某键失效 | 待测 |
| RGB | Vial 调节开关、亮度、颜色/模式，输入同时正常 | 待测 |

录像可按“全部键逐一输入 → Num 切换 → 拔插后再次输入”的顺序拍摄。屏幕不要包含密码或个人消息。将日期、结论和异常写入 `docs/test-report.md`，视频可作为后续 Release 附件上传。
