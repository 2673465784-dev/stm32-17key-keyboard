## 模型来源

[原项目附件](https://oshwhub.com/morempty/STM32-PAD-17jian-shuo-zi-jian-pa)提供 `5mm定位板.stl`、`W17PAD定位板.dxf`、`无刻外壳20230918.stl` 和 `奇怪的猫猫外壳.step` 等文件。本次作者确认沿用原博主的 3D 打印方案；这些是原作者模型。

2026-09-30 核对原项目说明后，整理如下建议。它们是原作者的方案，不是本次打印订单参数：

| 文件或部件 | 原作者说明 |
| --- | --- |
| `5mm定位板.stl` | 用于 3D 打印；优先推荐光固化，PLA 次之 |
| `W17PAD定位板.dxf` | 用于 PCB 定位板、亚克力、碳纤维或金属切割，不是直接打印的 STL |
| `无刻外壳20230918.stl` | 螺柱开槽 2.90 mm 已验证，可用 PLA；需在底部添加支撑并注意拆除 |
| `奇怪的猫猫外壳.step` | 可修改螺柱开槽和底部图案；修改后需重新核对与 PCB 的配合 |
| 紧固件 | 文中给出沉头 M2×8 螺丝、M2×3 螺柱；实际长度仍需匹配自己的打印件 |
| 外壳螺柱 | 原作者展示的光固化外壳使用胶粘螺柱，并建议 FDM 外壳考虑热熔螺母 |

## 装配检查顺序

1. 断开 Type-C，清理打印支撑和毛刺；试放 PCB，确认 USB 开口、螺丝孔和复位键位置匹配。
2. 先试装定位板、大键卫星轴与轴体，确认没有卡键。热插拔轴的两根金属针应插入轴座，不应折在轴座旁。
3. 使用长度合适的紧固件固定 PCB。检查螺丝、螺柱和外壳内壁没有压到元件或铜箔；不要靠拧紧螺丝强行拉平 PCB。
4. 装好键帽与脚垫，检查 `0`、`+`、`Enter` 的回弹和 USB 插头插拔空间。
5. 接线完成[验收清单](test-checklist.md)，确认装入外壳后没有新增卡键或接触问题。
